WType 0.2.1 fixes PDF heading sizes and Windows CI font initialization.

- **PDF headings:** all six heading levels now export at distinct sizes, including headings created with formatting commands. Inline italics and code formatting are preserved, and export sizes remain independent of editor zoom.
- **Windows CI:** load bundled fonts when the test application starts, preserving bold Markdown and searchable PDF text in headless environments without system fonts.

Download the archive for your platform below. Extract it and run WType; macOS users can move WType.app to Applications. SHA256SUMS.txt contains download checksums.
